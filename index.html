Featured project

    
Campus Admin Console

    

      

        
10,500 students, one fast dashboard

        
An admin console for a college where every student has a unique 8-digit registration number. Search, filter, sort and page through every record instantly, and see live statistics at a glance.

        
    
          
  • Server-side paging: the browser asks for 15 rows at a time, never all 10,500.
    • 
          
  • Unique IDs enforced by the database, so a duplicate can never be saved.
    • 
          
  • Hashed passwords with BCrypt and session-based login.
